A1.
[EN] The router treats Proto=47 as any other routed
     protocol. It looks up the destination IP in its

     as-is toward the outer Dst IP.

A3.
[EN] The router decapsulates the GRE packet. mGRE

A7.
[EN] Inner Src IP must be from the internal subnet,
     e.g. 10.0.0.99 (unused IP on 10.0.0.0/24).
     Must NOT be public IP because:

         same subnet as the receiving interface. A public
         IP like 8.8.8.8 does not match 10.0.0.0/24 —
         Hello rejected.

         never reaches attacker. Attack loop broken.

[TM] Inner Src IP internal subnet-லிருந்து இருக்கணும்,

A14.
[EN] OSPF Hello with TTL=64: When the inner packet is
     forwarded from the whitelist router's internal
     interface to the LAN, it is a routed packet. If
     OSPF Hello TTL=64, the target receives it with
     TTL=63 (after one hop decrement). OSPF on broadcast
     segments sends to multicast 224.0.0.5 and TTL must
     be 1 for link-local scope — TTL=64 would allow the
     multicast to propagate beyond the segment, which is
     not OSPF's intent and may cause issues.

[TM] OSPF Hello TTL=64 இருந்தால்: Inner packet whitelist
     router internal interface-லிருந்து LAN-க்கு forward
     ஆகும்போது routed packet. OSPF Hello TTL=64 என்றால்
     target TTL=63-ஆ receive பண்ணும் (one hop decrement).
     Broadcast segments-ல் OSPF multicast 224.0.0.5-க்கு
     அனுப்புது, TTL=1 link-local scope-க்கு தேவை.
     TTL=64 multicast-ஐ segment-க்கு அப்பால் propagate
     பண்ண allow பண்றது — OSPF-ஓட intent இல்லை, issues
     create பண்ணலாம்.

A15.

     TTL=1-உடன் internal LAN segment-ல் அனுப்பப்பட்ட

A17.

     172.16.0.1 on port 179 is accepted. Any other source

A19.

     inner Src IP. If inner Src=172.16.0.99 (unused fake

     with OSPF /32 route injection pointing 172.16.0.1 to
     attacker, the SYN-ACK is routed to the attacker who
     completes the handshake.

[TM] TCP-க்கு 3-way handshake வேண்டும். SYN-ACK inner
     Src IP-க்கு திரும்பும். Inner Src=172.16.0.99 (unused
     fake IP) என்றால் SYN-ACK 172.16.0.99-க்கு போகும்.
