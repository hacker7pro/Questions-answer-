A1.
[EN] Some Cisco IOS versions accept the command without
     a syntax error because the parser does not always
     validate that the tunnel destination is a valid unicast
     IP. However, the tunnel will NEVER come up because:
     (1) 224.0.0.5 is a link-local multicast address
         with TTL=1 — it cannot traverse routers.
     (2) GRE tunnel requires a point-to-point unicast
         destination to establish the virtual link.
     (3) The router has no mechanism to deliver a packet
         to a multicast group address as a tunnel endpoint.
     Result: Tunnel stays in DOWN/DOWN state permanently.

[TM] சில Cisco IOS versions syntax error இல்லாம command
     accept பண்றது — parser எப்போதும் tunnel destination

     ஆனால் tunnel NEVER up ஆகாது, ஏனென்றால்:
     (1) 224.0.0.5 link-local multicast address, TTL=1 —
         routers-ஐ traverse பண்ண முடியாது.
     (2) GRE tunnel virtual link establish பண்ண point-to-point

A3.

A55.
[EN] Risk Summary:
     mGRE tunnels without authentication accept GRE packets
     from ANY internet source. When routing protocols
     (OSPF, EIGRP) run on the internal LAN without MD5
     authentication, an attacker can inject valid protocol
     Hello packets and LSAs/Updates using link-local
     multicast destinations (224.0.0.5 for OSPF,
     224.0.0.10 for EIGRP) as the inner packet destination.
     These multicast addresses do not require PIM — they
     are link-local and delivered directly by the network
     stack after GRE decapsulation, making PIM a non-factor
     in this attack. Once a routing protocol adjacency
     forms, the attacker can inject fake routes to redirect
     traffic, black-hole services, or establish BGP sessions
     for full route table control. The recommended fix is
     two-layered: (1) Block GRE inbound from untrusted
     sources at the internet-facing interface with an ACL
     denying Proto 47 (and 4, 41, 97) from any external
     source, and (2) Enable MD5 authentication on all
     interior routing protocols to prevent injection even
     if GRE reaches the LAN.
